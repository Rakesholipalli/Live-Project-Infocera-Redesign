TROUBLESHOOTING:
----------------
❌ MongoDB connection failed?
   → Check password in backend/.env
   → Verify MongoDB cluster is active

❌ Port 5000 already in use?
   → Run: netstat -ano | findstr :5000
   → Kill: taskkill /PID <PID> /F

❌ Backend won't start?
   → Run: cd backend && npm install
   → Then: npm run dev
